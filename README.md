# keijiban

PHP + MySQLで作成したシンプルな掲示板です。  
2023年作成。LAMP環境で動作します。

## 機能

- 名前と本文を投稿
- 投稿内容をMySQLに保存
- 投稿番号・投稿日時を表示
- レスポンシブ対応
- PC表示時に広告スペースを表示

## 構成

```text
keijiban/
├── index.php
├── send.php
├── db_info.php
├── styles.css
├── keijiban.sql
├── 縦長.png
├── 正方形.png
└── logo.png
```

## DB構築

```bash
mysql -u root -p < keijiban.sql
```

`db_info.php` の接続情報は、自分の環境に合わせて変更してください。

## 工夫した点

- SQLインジェクション対策として、投稿内容をデータベースへ保存する際に `mysqli_real_escape_string()` を使用して特殊文字をエスケープしました。
- 画面幅に応じてレイアウトが変化するレスポンシブデザインにしました。
- PC表示では、掲示板の左右に縦長広告を配置できるデザインにしました。

## 今後の展望

投稿を指定して返信できるアンカー機能を追加したいです。また、アンカーの上にマウスを置いたら、その番号の投稿がポップアップで表示できる機能も追加したいです。
